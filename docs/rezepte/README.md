# Rezepte – was Jarvis gelernt hat

Ein Rezept = eine Aufgabe, die Jarvis schon einmal gelöst hat. Jarvis legt neue Rezepte SELBST an, sobald er etwas
Neues herausgefunden hat (eine Datei pro Thema, Dateiname = Thema in Kleinbuchstaben mit Bindestrichen).
Die erste Zeile (# Titel) und die Zeile "Wann:" werden beim Start als Übersicht geladen – kurz und eindeutig halten.

Aufbau:
  # <Titel>
  Wann: <in welcher Situation das Rezept passt – ein Satz>
  ## Schritte
  ## Befehle
  ## Stolperfallen
  Zuletzt geprüft: <Datum>
- Screenshot Tablet auf Drive (docs/rezepte/screenshot-tablet-drive.md)

- Garmin-Uhr auswerten (docs/rezepte/garmin-auswertung.md) – Harry fragt nach Puls-/Stressverlauf, Auswertung oder "synchronisiere die Uhr".
